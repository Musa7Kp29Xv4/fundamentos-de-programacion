# RUCAM – Sistema de Registro de Ventas

## Descripción
RUCAM es un prototipo desarrollado en Python para apoyar el registro de ventas de una tienda familiar de abarrotes y cremería.

## Objetivo
Facilitar el registro de productos, el cálculo de ventas y la consulta de los ingresos acumulados.

## Productos
- Maruchan: $20
- Queso Oaxaca: $25
- Huevo por kilo: $46
- Sabritas: $22
- Rollo de papel suelto: $14
- Cigarros sueltos: $8

## Funcionalidades
1. Registrar ventas.
2. Calcular automáticamente el total.
3. Seleccionar pago en efectivo o tarjeta.
4. Consultar el resumen de ventas.
5. Salir del programa.

## Tecnologías
- Python
- Visual Studio Code
- PSeInt
- Jupyter Notebook
- Git y GitHub

La estructura del proyecto RUCAM está organizada en dos carpetas principales: Avance_Proyecto, donde se encuentran el documento de la Fase I, el diagrama de flujo y el código prototipo_inicial.py; y Semana3, que contiene el notebook practica_semana3.ipynb. Además, en la carpeta principal se encuentra el archivo README.md con la información general del proyecto.

## Ejecución
1. Descargar o clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar el archivo:

```bash
python prototipo_inicial.py
```

## Alcance
El prototipo registra las ventas durante la ejecución del programa. No cuenta todavía con base de datos ni almacenamiento permanente.

## Conclusión
Este proyecto permite aplicar los fundamentos de programación en una situación real, utilizando RUCAM como caso de estudio.
